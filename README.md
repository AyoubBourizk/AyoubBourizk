## À propos

Je construis des **projets bout en bout** : hardware, firmware, backends, interfaces web et données. J’aime quand la stack est cohérente, le code lisible, et qu’on sent le soin du détail — du schéma UML au pixel sur l’UI.

**Actuellement** : Manager chez **Drogerie Al-khalil** · **3ᵉ année** en *Ingénierie Informatique et Réseaux* à l’**EMSI** (Tanger, Maroc).
